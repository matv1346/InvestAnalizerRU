# Investment Analyzer - Анализ инвестиционного портфеля

Профессиональное десктопное приложение для Windows на стеке Python (PySide6) для агрегации, очистки и анализа инвестиционных данных от любых брокеров.

## 🚀 Основные возможности

### Модуль 1: Интеллектуальный Data Pipeline и RLHF-парсер
- Импорт файлов Excel (.xlsx) и CSV от любых брокеров
- Автоматическое определение брокера по структуре файла
- Диалог ручного указания брокера при неопределенности
- Поиск и удаление дубликатов транзакций
- Удаление отчетов с каскадным удалением транзакций
- **Интерактивный чат с ИИ-парсером** для обучения на фидбеке пользователя
- Сквозной расчет налогов и комиссий (FIFO метод)

### Модуль 2: Интеграция с API Мосбиржи (ISS Moex)
- Фоновая загрузка актуальных котировок
- Исторические данные для графиков
- Метаданные активов (сектор, тип бумаги, валюта)
- Кросс-курсовой движок для валютных активов

### Модуль 3: Интерактивный реестр сделок (Drill-Down)
- Уровень 1: Глобальный реестр по всем брокерам
- Уровень 2: Детализация по конкретному брокеру
- Уровень 3: Первoисточник до конкретного файла
- Фильтры по типу, дате, тикеру

### Модуль 4: Аналитика и Конструктор Отчетов
- Сводная аналитика портфеля
- Конструктор графиков (Line, Bar, Donut, Candlestick)
- Пользовательские дашборды с сохранением
- Экспорт в XLSX / CSV / PDF

### Модуль 5: ИИ-Советник и Калькулятор Ребалансировки
- Инвестиционные рекомендации ИИ
- Анализ рисков и концентрации
- Калькулятор ребалансировки с учетом риск-профиля
- Пошаговый план закупки с обоснованием

### Продвинутые математические функции
- **XIRR** - точный расчет доходности методом Ньютона-Рафсона
- **FIFO** - налоговый расчет по методу первых покупок
- **Кросс-курсы** - конвертация валют по историческим курсам

## 🤖 RLHF-обучение парсера

Приложение поддерживает обучение на основе обратной связи пользователя через чат:

1. Пользователь замечает ошибку парсинга
2. Пишет в чат естественным языком (например: "В отчетах ВТБ строки 'Списание спец. комиссии' нужно привязывать к комиссии за сделки")
3. ИИ создает правило в таблице `parsing_rules`
4. Правило применяется ко всем будущим импортам
5. Возможность перепарсить существующие данные

## 📊 Примеры использования

### Расчет XIRR
```python
from database import get_database

db = get_database()
cash_flows = db.get_cash_flows_for_xirr(
    start_date=date(2024, 1, 1),
    end_date=date(2024, 12, 31)
)
xirr = db.calculate_xirr(cash_flows)
print(f"Доходность портфеля: {xirr*100:.2f}% годовых")
```

### Налоговый расчет FIFO
```python
tax_lots = db.calculate_fifo_tax(
    broker_id=1,
    asset_id=42,
    tax_year=2024
)
total_tax = sum(lot['tax_amount'] for lot in tax_lots if lot['taxable'])
```
